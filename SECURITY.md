# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it
privately through the repository maintainer’s GitHub profile:

<https://github.com/devtechedge>

Include a clear description, reproduction steps, impact assessment, and any
suggested mitigation. Please allow reasonable time for investigation before
public disclosure.
